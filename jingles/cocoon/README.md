# Cocoon Directory
This directory is for hosting content used within Cocoon itself, rather than jingles for specific games or apps.\
You can upload both music and sound effects here for use within the Cocoon app. 

See below what the folders are for and how to structure your files.

**NOTE: Please do NOT delete any "test" files until there is at least one user folder/file within the directory.**

## Miscellaneous:
Use this for any uncategorised audio.\
There are sub-folders inside for music and sound effects.

## Music Packs:
Create a folder here with your username and then, within your user folder, create a playlist or pack folder.

*For example:* ***music-packs/SJH/ACNH-Hourly-Music/***

These packs are for use in the Cocoon home screen, either as timed or playlisted tracks.

## SFX Packs:
Please create a folder here with your username and then, within your user folder, create a sound pack folder.

*For example:* ***sfx-packs/SJH/pokemon-sfx-pack/***

These packs are for use in the Cocoon home screen using the built-in sfx-replacing tools.

## Formatting and Crediting
For any music hosted in these folders, please use the following format:\
Author/Artist - Song Name/Description (Username)

*For example:* ***Nintendo - Animal Crossing Main Theme (SJH)***

## Extra Notes
Keeping this format makes finding content easier, as the files will be grouped alphabetically by artist rather than song name.\
It also ensures that you are still credited for providing the music and for any extra processing work you may do before uploading here.

Thank you!
