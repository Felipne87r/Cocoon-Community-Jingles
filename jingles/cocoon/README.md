# Cocoon Community Jingles Pack
*Ethically sourced from the Cocoon community.*


This directory is for music within Cocoon itself rather than jingles for specific games or apps.

Miscellaneous:
Use this for any uncategorised audio. There are sub-folders inside for music and sound effects.

Music Packs:
Create a folder here with your username and then, within your user folder, create a playlist or pack folder.
For example: music-packs/SJH/ACNH-Hourly-Music
These packs are for use in the Cocoon home screen, either as timed or playlisted tracks.
